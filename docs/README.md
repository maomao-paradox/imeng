# 梦境记录与词网络 Web 应用 — 完整产品功能提示词

## 一、产品定位

一款面向个人的梦境记录与探索工具。用户记录梦境后，系统自动提炼关键词并生成词节点网络；通过日历回溯历史梦境；在联机模式下，可浏览公开梦境，并基于今日梦境的关键词匹配到语义相近的其他用户梦境。

**核心价值**：把模糊、易忘的梦境转化为可沉淀、可回溯、可连接的数据。

**形态**：Web 端应用（响应式，优先适配移动端浏览器，兼顾桌面端）。

---

## 二、目标用户与场景

| 用户类型 | 核心诉求 |
|---|---|
| 梦境记录爱好者 | 快速记录、长期保存、可视化回顾 |
| 自我探索者 | 发现反复出现的主题、情绪模式 |
| 社交好奇者 | 看看陌生人的梦里有什么，找到"同梦人" |

**典型场景**：清晨醒来，趁记忆还清晰，用手机或电脑快速记下梦境 → 系统即时提炼关键词 → 看到当天的词网络 → 若开启联机，发现有人梦到了相似的意象。

## 三、功能模块

### 模块 1：梦境记录

#### 1.1 新建梦境
- 富文本输入框，支持长文本（建议上限 5000 字）
- 记录字段：
  - 梦境正文（必填）
  - 日期（默认今天，可修改）
  - 情绪标签（可选，多选）：平静 / 喜悦 / 恐惧 / 焦虑 / 悲伤 / 愤怒 / 困惑 / 奇妙
  - 清晰度评分（1~5 星）
- 支持语音输入（Web Speech API，浏览器原生）
- 草稿自动保存（localStorage），防止意外丢失

#### 1.2 关键词提炼
- 提交后调用 LLM，从梦境文本中提取 3~8 个关键词
- 关键词类型需覆盖：
  - 核心意象（如"蛇""楼梯"）
  - 情绪词（如"坠落感"）
  - 场景词（如"学校""海边"）
- 每个关键词附带权重（0~1），用于后续节点大小渲染
- 用户可手动增删、修改关键词，修改后词网络实时更新

#### 1.3 梦境列表
- 按时间倒序展示所有梦境
- 每条显示：日期、正文摘要（前 80 字）、关键词标签、情绪标签
- 支持搜索（全文检索）、按情绪/关键词筛选

---

### 模块 2：词节点网络

#### 2.1 网络生成
- 以单条梦境为单位，将其关键词渲染为节点
- 节点大小 = 关键词权重
- 关联判断规则（可配置）：
  - **同源关联**：同一条梦境的关键词默认全部互连（弱连接）
  - **语义关联**：通过 Embedding 计算关键词相似度，超过阈值（如 0.75）则建立强连接
  - **跨梦境关联**：同一用户历史梦境中出现过的相同/相似关键词，建立跨条目连接
- 无任何关联的词，孤立显示在画布边缘

#### 2.2 交互
- 力导向布局，节点可拖拽，画布可缩放 / 平移
- 点击节点：高亮其所有连接边，侧边栏显示该词出现的所有梦境
- 悬停节点：显示 tooltip（词、权重、出现次数）
- 支持切换视图：单条梦境网络 / 个人全部梦境总网络

#### 2.3 视觉
- 节点颜色按情绪或词性分类
- 边的粗细代表关联强度
- 深色主题优先（贴合"梦境"氛围），支持浅色切换

---

### 模块 3：日历视图

#### 3.1 月历展示
- 标准月历网格，每格显示日期
- 有梦境记录的日期，格子内显示圆点或缩略标记
- 圆点数量 / 颜色可反映当天记录条数或主导情绪

#### 3.2 日期交互
- 点击某一天：展开当天所有梦境列表
- 无记录的日期：显示"这天没有记录梦境"及快捷新建入口
- 支持左右切换月份、快速回到今天

#### 3.3 数据概览
- 顶部显示：本月记录天数、总梦境数、高频关键词 Top 5
- 可选：月度情绪分布小图表

---

### 模块 4：联机模式

#### 4.1 隐私与公开
- 每条梦境有独立开关：**仅自己可见 / 公开**
- 默认关闭（隐私优先）
- 公开的梦境可选择是否匿名展示（隐藏用户名，仅显示头像或随机昵称）

#### 4.2 公开梦境流
- 时间线形式展示所有公开梦境
- 每条显示：日期、摘要、关键词标签、情绪标签、模糊化后的用户标识
- 支持按关键词、情绪筛选
- 支持点赞 / 共鸣（可选互动，不显示具体用户）

#### 4.3 梦境匹配
- 基于"今日你的梦境关键词"，匹配语义相近的其他用户公开梦境
- 匹配算法：关键词 Embedding 余弦相似度 / Jaccard 相似度，返回 Top N（如 5~10 条）
- 匹配结果展示：相似梦境摘要、共同关键词高亮、相似度百分比
- 入口：记录完今天的梦境后，首页卡片提示"有 3 个陌生人和你梦到了相似的意象"

#### 4.4 同梦人（可选进阶）
- 若双方互相匹配度极高，可发起匿名"同梦"标记（不暴露身份）
- 形成"今日同梦"聚合页：展示今天所有共享某关键词的梦境数量

---

### 模块 5：个人中心

- 用户注册 / 登录（邮箱或第三方 OAuth）
- 个人统计：总梦境数、连续记录天数、高频关键词云
- 设置：主题切换、关键词提炼偏好（数量 / 类型）、隐私默认值、数据导出（JSON / Markdown）
- 数据删除：单条删除、全部清空

## 四、页面结构

| 页面 | 路径 | 核心内容 |
|---|---|---|
| 首页 / 今日 | `/` | 今日梦境状态、快捷记录入口、匹配提示 |
| 记录梦境 | `/record` | 新建 / 编辑梦境表单 |
| 梦境详情 | `/dream/:id` | 正文、关键词、词网络、情绪 |
| 梦境列表 | `/dreams` | 全部记录、搜索、筛选 |
| 词网络 | `/network` | 个人总网络图 |
| 日历 | `/calendar` | 月历视图、按日查看 |
| 联机广场 | `/explore` | 公开梦境流 |
| 匹配结果 | `/match` | 今日匹配到的相似梦境 |
| 个人中心 | `/profile` | 统计、设置、导出 |

## 五、技术栈建议（Web 端）

| 层 | 推荐方案 | 说明 |
|---|---|---|
| 前端框架 | React / Vue 3 / Svelte | 任选，React 生态最丰富 |
| 词网络可视化 | `react-force-graph` / `v-network-graph` / `plough` | 力导向图，支持交互 |
| 日历组件 | `react-calendar` / `v-calendar` | 成熟组件，快速接入 |
| 状态管理 | Zustand / Pinia | 轻量即可 |
| 样式 | Tailwind CSS | 快速构建深色主题 |
| 后端 | Node.js (Express/Fastify) 或 Python FastAPI | 提供 API |
| 数据库 | PostgreSQL / SQLite（初期） | 存用户、梦境、关键词 |
| LLM 关键词提取 | OpenAI API / Gemini API / 本地 Ollama | Prompt 结构化输出 JSON |
| Embedding 匹配 | OpenAI Embeddings / 本地 sentence-transformers | 计算关键词相似度 |
| 部署 | Vercel（前端）+ Railway/Fly.io（后端） | 低成本起步 |

## 七、开发优先级（MVP → 进阶）

**MVP（第一版）**
1. 用户登录
2. 梦境记录 + LLM 关键词提炼
3. 单条梦境的词节点网络
4. 梦境列表 + 日历视图

**第二版**
5. 个人总词网络
6. 公开梦境流
7. 基于关键词的梦境匹配

**第三版**
8. 同梦人聚合
9. 数据统计与导出
10. 语音输入、情绪分析等增强
