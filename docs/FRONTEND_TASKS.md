# 前端工作清单

依据：梦境记录与词网络 Web 应用产品说明。前端使用 React + TypeScript，优先适配桌面端，同时兼容移动端。

## 开工准备

- [x] 确认 React Router v6、Zustand、Tailwind、SVG 词网络和原生月历，保持 React + TypeScript 技术栈。
- [x] 建立前端项目骨架、开发/构建脚本、环境配置和 ESLint/Vitest/TypeScript 质量检查。
- [x] 与后端对齐 API 契约：HttpOnly Cookie 认证、梦境/关键词字段、分页筛选、错误格式和日历日期。
- [x] 建立响应式页面外壳、深浅主题、加载/空/错误状态。

## MVP（第一版）

### 应用框架与认证

- [x] 实现响应式应用外壳及首页、记录、详情、列表、日历、词网络、个人中心等路由。
- [x] 实现邮箱注册、登录、登出及未登录访问限制；会话由 HttpOnly Cookie 管理。
- [x] 实现统一 API 客户端，携带凭据并处理请求错误、加载状态和会话失效。

### 梦境记录与关键词

- [x] 实现新建/编辑梦境表单：必填正文（最多 5000 字）、日期、可多选情绪和 1～5 星清晰度。
- [x] 提供本地草稿自动保存与恢复，并允许用户清除草稿。
- [x] 提交梦境并展示关键词提炼状态及明确的失败/未配置提示。
- [x] 支持手动增删、修改关键词；保存后刷新相关网络视图。
- [x] 实现梦境详情页，展示正文、日期、情绪、清晰度、关键词及单条梦境词网络。

### 梦境列表与日历

- [x] 实现按时间倒序、分页的梦境列表，展示日期、80 字摘要、关键词和情绪。
- [x] 支持全文搜索以及按情绪、关键词筛选，并提供无结果状态。
- [x] 实现月历、月份切换和返回今天；按记录日期显示标记，点击日期查看当天梦境。
- [x] 对无记录日期展示空状态和快捷新建入口；展示本月记录天数、梦境数和高频关键词 Top 5。

### 词网络

- [x] 使用 Cytoscape 实现单条梦境及个人总词网络：按关键词权重/出现频率渲染节点、按共现次数渲染边。
- [x] 支持节点拖拽、画布缩放/平移、悬停提示和点击关键词高亮关联网络并查看梦境。
- [x] 点击节点时展示该词其他梦境；提供适配窄屏的纵向详情。
- [x] 提供深色优先主题和浅色切换；网络空数据状态清晰可见。

## 第二版

- [x] 实现独立的个人全部梦境总网络页，支持关键词频次大小、同梦连线及点击查看关联梦境。
- [x] 实现公开梦境广场：时间线、关键词/情绪筛选、匿名用户标识。
- [x] 提供每条梦境的公开/仅自己可见开关和匿名展示选项，明确展示隐私状态。
- [x] 实现梦境匹配结果页，呈现相似度、共同关键词和匹配梦境摘要。
- [x] 在首页展示今日梦境匹配提示；仅在有匹配结果时呈现有效入口。
- [x] 若后端支持互动，实现匿名点赞/共鸣及即时状态反馈。
