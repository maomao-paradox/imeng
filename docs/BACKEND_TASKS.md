# 后端工作清单

依据：梦境记录与词网络 Web 应用产品说明。后端以 Python 为主，MVP 暂用 FastAPI + SQLite；LLM / Embedding 提供方需在开工前确定。

## 开工准备

- [x] 按 Python + FastAPI、异步 SQLAlchemy、SQLite、Alembic 建立服务方案；认证使用邮箱/密码和 HttpOnly Cookie。
- [x] 发布 API 契约：字段、校验规则、分页/筛选参数、错误格式、日期规则和认证要求见 `/docs`。
- [x] 建立 FastAPI 服务骨架、环境配置、健康检查、测试和数据库迁移流程；数据访问层与配置支持未来更换数据库。
- [x] 统一输入校验、错误响应、鉴权与所有权校验；梦境默认仅本人可访问。

## MVP（第一版）

### 用户与认证

- [x] 实现邮箱注册、登录、登出及当前用户接口；密码使用 PBKDF2-HMAC-SHA256，opaque 会话仅以哈希存储，Cookie 为 HttpOnly。
- [ ] 如选用第三方 OAuth，定义提供方、回调流程及账号关联策略。
- [x] 为用户资源实施所有权校验，避免跨用户读取、修改或删除梦境。

### 梦境与关键词

- [x] 建立用户、梦境、关键词、会话数据模型及 Alembic 迁移。
- [x] 实现梦境创建、详情、编辑、删除、列表和全文搜索 API；校验正文必填且不超过 5000 字。
- [x] 实现情绪、日期、清晰度、分页及排序等查询参数校验；列表默认按时间倒序。
- [x] 提供可配置的关键词提炼适配器接口；支持提取 3～8 个关键词及 0～1 权重，编辑正文后重新提炼。
- [x] 校验适配器输出；失败时记录不含梦境正文的错误日志、不中断梦境保存，并在响应中标记提炼状态。
- [x] 实现关键词批量手动增删改 API，并在修改后使关联词网络数据保持一致。
- [ ] 配置并接入实际 LLM 供应方（按决策暂不接入）。

### 词网络

- [x] 实现单条梦境网络数据接口，返回节点、权重、出现次数、关联梦境和边/关联强度，支持孤立节点。
- [x] 实现同一梦境关键词之间的弱连接；语义关联作为后续能力。
- [x] 为网络接口校验梦境归属，确保用户只能访问自己的私有梦境网络。

### 列表与日历支持

- [x] 实现梦境全文检索及按情绪、关键词、日期范围筛选。
- [x] 实现按月份汇总的日历接口，返回每日记录数量/主导情绪、记录天数、梦境总数及高频关键词 Top 5。
- [x] 使用日历日期字段处理日期筛选和月历归档，并校验日期范围。

## 第二版

### 个人总网络

- [x] 聚合用户全部梦境中的相同关键词，按共同出现梦境数量建立关联并返回关联梦境。
- [ ] 如启用语义关联，接入 Embedding 生成与存储，按可配置阈值（建议初始 0.75）建立强连接。
- [x] 为网络规模定义裁剪策略：最多 200 个关键词、1000 条连线，每个关键词返回最近 20 条关联梦境，并标记响应是否截断。

### 联机模式与匹配

- [x] 实现公开状态和匿名设置 API；新梦境默认仅自己可见，并确保私有梦境不会出现在公开查询中。
- [x] 实现公开梦境流及关键词、情绪筛选；仅返回允许公开的字段和匿名化标识。
- [x] 若实现点赞/共鸣，提供不暴露互动者身份的接口及防重复规则。
- [x] 实现今日梦境匹配：仅以当前用户今日关键词匹配其他用户公开梦境，返回 Top N、相似度和共同关键词。
- [x] 选择并实现匹配算法（Jaccard）；对关键词去重、按相似度及日期排序，返回 Top 5，空关键词时返回空结果。
- [x] 提供首页匹配摘要和匹配结果接口，并验证结果不泄漏私有梦境或用户身份。

## 第三版 / 增强项

- [ ] 实现个人统计接口：梦境总数、连续记录天数、高频关键词及月度情绪分布所需数据。
- [ ] 实现用户设置读写：主题、关键词提炼偏好和默认隐私值。
- [ ] 实现 JSON / Markdown 数据导出及单条删除、清空全部数据 API；定义删除范围和确认/异步策略。
- [ ] 评估并实现高匹配度匿名“同梦”标记和按关键词聚合的“今日同梦”数据接口。
- [ ] 评估语音转写/情绪分析是否应由前端浏览器或后端服务负责，明确隐私和供应商数据处理要求。

## 质量、安全与运维验收

- [x] 为认证、梦境 CRUD、所有权隔离、关键词、列表筛选、日历、公开状态/匿名化、广场过滤、共鸣和今日匹配编写自动化测试。
- [x] 处理关键词适配器未配置、输出无效及运行异常；错误显式显示提炼状态并可观测，不伪造成功结果。
- [x] 对注册/登录实施进程内频率限制和请求校验；日志不记录梦境正文、密码或密钥。
- [x] 验证私有数据访问控制；MVP 不提供公开梦境接口。
- [ ] 配置数据库备份/恢复、迁移发布、健康检查、错误监控和 LLM 用量/成本监控。
- [x] 与前端联调 API 契约、日期时区、分页筛选、错误响应和会话过期行为。
