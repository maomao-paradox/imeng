# 前端工作清单

依据：梦境记录与词网络 Web 应用产品说明。前端使用 React + TypeScript，优先适配桌面端，同时兼容移动端。

## 开工准备

- [ ] 确认路由、状态管理、样式方案和词网络/日历组件，并与 React + TypeScript 技术栈保持一致。
- [ ] 建立前端项目骨架、开发/构建脚本、环境配置和基础质量检查。
- [ ] 与后端确认 API 契约：认证方式、梦境/关键词字段、分页筛选、错误格式及日期时区规则。
- [ ] 定义设计基础：响应式断点、深浅主题、颜色与情绪标签映射、加载/空/错误状态。

## MVP（第一版）

### 应用框架与认证

- [ ] 实现响应式应用外壳及首页、记录、详情、列表、日历、词网络、个人中心等路由。
- [ ] 实现注册、登录、登出及未登录访问限制；根据后端认证方案安全管理会话。
- [ ] 实现统一 API 客户端，处理认证状态、请求错误、加载状态和会话失效。

### 梦境记录与关键词

- [ ] 实现新建/编辑梦境表单：必填正文（最多 5000 字）、日期、可多选情绪和 1～5 星清晰度。
- [ ] 提供本地草稿自动保存与恢复，避免覆盖已提交内容，并允许用户清除草稿。
- [ ] 提交梦境并展示关键词提炼进度、成功结果及可恢复的失败提示。
- [ ] 支持手动增删、修改关键词；保存后刷新相关网络视图。
- [ ] 实现梦境详情页，展示正文、日期、情绪、清晰度、关键词及单条梦境词网络。

### 梦境列表与日历

- [ ] 实现按时间倒序的梦境列表，展示日期、80 字摘要、关键词和情绪。
- [ ] 支持全文搜索以及按情绪、关键词筛选，并提供清空筛选和无结果状态。
- [ ] 实现月历、月份切换和返回今天；按记录日期显示标记，点击日期查看当天梦境。
- [ ] 对无记录日期展示空状态和快捷新建入口；展示本月记录天数、梦境数和高频关键词 Top 5。

### 词网络

- [ ] 实现单条梦境的力导向词网络：按权重渲染节点、按关联强度渲染边。
- [ ] 支持节点拖拽、画布缩放/平移、悬停提示和节点点击高亮。
- [ ] 点击节点时展示该词关联的梦境；为窄屏提供可用的详情呈现方式。
- [ ] 提供深色优先的主题和浅色切换；网络加载、空数据和渲染错误状态清晰可见。

## 第二版

- [ ] 实现个人全部梦境总网络及单条/总网络视图切换。
- [ ] 实现公开梦境广场：时间线、关键词/情绪筛选、匿名用户标识。
- [ ] 提供每条梦境的公开/仅自己可见开关和匿名展示选项，明确展示隐私状态。
- [ ] 实现梦境匹配结果页，呈现相似度、共同关键词和匹配梦境摘要。
- [ ] 在首页展示今日梦境匹配提示；仅在有匹配结果时呈现有效入口。
- [ ] 若后端支持互动，实现匿名点赞/共鸣及即时状态反馈。

## 第三版 / 增强项

- [ ] 实现个人统计：梦境总数、连续记录天数和高频关键词云。
- [ ] 实现设置：主题、关键词提炼偏好、隐私默认值。
- [ ] 实现 JSON / Markdown 数据导出入口及下载反馈。
- [ ] 实现单条删除和清空全部数据的确认流程及结果反馈。
- [ ] 按产品优先级评估语音输入（Web Speech API）、月度情绪分布、情绪分析和“今日同梦”聚合页。

## 验收与联调

- [ ] 验证移动端与桌面端核心流程：登录 → 记录 → 查看关键词/网络 → 列表/日历回看。
- [ ] 验证刷新、重复提交、网络失败、空数据、无权限和会话过期等状态。
- [ ] 验证草稿恢复、日期展示、筛选组合、主题切换及键盘/屏幕阅读器基本可用性。
- [ ] 与后端联调 API 字段、分页、权限和错误提示；检查无障碍及浏览器控制台错误。
