# 后端工作清单

依据：梦境记录与词网络 Web 应用产品说明。后端以 Python 为主，MVP 暂用 FastAPI + SQLite；LLM / Embedding 提供方需在开工前确定。

## 开工准备

- [ ] 按 Python + FastAPI、SQLite 建立服务方案；确定迁移方案、认证方式、部署环境及密钥管理方案。
- [ ] 定义并发布 API 契约：字段、校验规则、分页/筛选参数、错误格式、日期时区和认证要求。
- [ ] 建立 FastAPI 服务骨架、环境配置、日志、健康检查、测试和 SQLite 数据库迁移流程；保持数据访问层便于未来更换数据库。
- [ ] 统一输入校验、错误响应、鉴权与所有权校验；明确梦境数据的隐私和删除策略。

## MVP（第一版）

### 用户与认证

- [ ] 实现邮箱注册、登录、登出及当前用户接口；确定密码策略、会话/token 生命周期和凭据安全存储。
- [ ] 如选用第三方 OAuth，定义提供方、回调流程及账号关联策略。
- [ ] 为用户资源实施所有权校验，避免跨用户读取、修改或删除梦境。

### 梦境与关键词

- [ ] 建立用户、梦境、关键词数据模型及迁移；梦境包含正文、日期、情绪数组、清晰度、公开/匿名状态和创建时间。
- [ ] 实现梦境创建、详情、编辑、删除、列表和全文搜索 API；校验正文必填且不超过 5000 字。
- [ ] 实现情绪、日期、清晰度、分页及排序等查询参数校验；列表默认按时间倒序。
- [ ] 对新建/编辑梦境调用 LLM 提取 3～8 个关键词，覆盖核心意象、情绪词和场景词，返回 0～1 权重。
- [ ] 对 LLM 输出进行结构化解析和字段校验；明确超时、限流、无效输出和上游不可用时的错误处理及重试策略。
- [ ] 实现关键词手动增删改 API，并在修改后使关联词网络数据保持一致。

### 词网络

- [ ] 实现单条梦境网络数据接口，返回节点、权重及边/关联强度，支持无关联关键词。
- [ ] 定义并实现首版关联规则；若 MVP 仅提供同源弱连接，应在 API 契约中明确，语义关联作为后续能力。
- [ ] 为网络接口校验梦境归属，确保用户只能访问自己的私有梦境网络。

### 列表与日历支持

- [ ] 实现梦境全文检索及按情绪、关键词筛选。
- [ ] 实现按月份汇总的日历接口，返回每日记录数量/主导情绪、记录天数、梦境总数及高频关键词 Top 5。
- [ ] 处理日期边界与时区，确保创建、筛选和月历归档一致。

## 第二版

### 个人总网络

- [ ] 实现用户全部梦境的关键词网络聚合及跨梦境相同/相似词关联。
- [ ] 如启用语义关联，接入 Embedding 生成与存储，按可配置阈值（建议初始 0.75）建立强连接。
- [ ] 为网络规模定义分页/裁剪策略，确保用户历史数据增多时接口仍可用。

### 联机模式与匹配

- [ ] 实现公开状态和匿名设置 API；新梦境默认仅自己可见，并确保私有梦境不会出现在公开查询中。
- [ ] 实现公开梦境流及关键词、情绪筛选；仅返回允许公开的字段和匿名化标识。
- [ ] 若实现点赞/共鸣，提供不暴露互动者身份的接口及防重复规则。
- [ ] 实现今日梦境匹配：仅以当前用户今日关键词匹配其他用户公开梦境，返回 Top N、相似度和共同关键词。
- [ ] 选择并实现匹配算法（Embedding 余弦相似度或 Jaccard）；定义去重、阈值、排序和无结果行为。
- [ ] 提供首页匹配摘要和匹配结果接口，并验证结果不泄漏私有梦境或用户身份。

## 第三版 / 增强项

- [ ] 实现个人统计接口：梦境总数、连续记录天数、高频关键词及月度情绪分布所需数据。
- [ ] 实现用户设置读写：主题、关键词提炼偏好和默认隐私值。
- [ ] 实现 JSON / Markdown 数据导出及单条删除、清空全部数据 API；定义删除范围和确认/异步策略。
- [ ] 评估并实现高匹配度匿名“同梦”标记和按关键词聚合的“今日同梦”数据接口。
- [ ] 评估语音转写/情绪分析是否应由前端浏览器或后端服务负责，明确隐私和供应商数据处理要求。

## 质量、安全与运维验收

- [ ] 为认证、梦境 CRUD、所有权隔离、关键词校验、日历汇总和公开过滤编写自动化测试。
- [ ] 测试 LLM / Embedding 上游超时、限流、异常响应和配置缺失；错误应明确返回并可观测，不静默伪造成功结果。
- [ ] 对认证与写操作实施适当的限流、请求校验和安全日志；日志不得包含梦境正文、密码或密钥。
- [ ] 验证私有数据访问控制、公开字段白名单、匿名化、删除后不可读及导出权限。
- [ ] 配置数据库备份/恢复、迁移发布、健康检查、错误监控和 LLM 用量/成本监控。
- [ ] 与前端联调 API 契约、日期时区、分页筛选、错误响应和会话过期行为。
